# About these documents

The six documents in this folder (`refund_policy.md`, `delivery_sla.md`, `seller_guidelines.md`, `review_moderation.md`, `data_dictionary.md`, `metrics_glossary.md`) are **synthetic**. They were written for the "Hybrid Analyst" university project (Agentic AI, B.Tech CSE, Karnavati University).

- They are **not** real Olist policies. Olist did not publish them, and the numbers in them (thresholds, percentages, fees, deadlines) are invented for the project.
- The table and column facts in `data_dictionary.md` follow the public Olist Brazilian E-Commerce dataset.
- Benchmarks quoted in the documents are policy examples, not measured results. Measured values come only from querying the database.
